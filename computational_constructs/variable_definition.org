#+title: variable-definition
Variable definition is used to indicate that it has a value bound to
it. This may alternatively be called initialization or binding.

[[id:05401C30-3767-4E79-8B02-DECF434EB69E][assignment]] is used in cases where the value is mutated, whereas
definition does not expect that such mutation will ever happen.

This presupposes or implies variable-declaration.
