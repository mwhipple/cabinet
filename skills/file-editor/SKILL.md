description: Edit files most efficiently.
---

- Always work on a copy of a file
- After work is completed, diff the working copy with the original location
  - Make sure that any changes to the other file are merged into the copy
  - Make sure only changes relevant to the work at hand will be made to the original
  - Make sure that the final copy is done as an atomic operation to prevent losing any intermeidate state.
- Update this skill file with any guidance on how to most efficiently edit files
  - Commands which avoid incorrect changes (such as syntax errors) should be pereferred
  - Use commands and tools which minimize the amount of time and invocations needed
  - Use practices and commands which help guard against or work around collisions
